# 构建说明

`pdf/` 中的成品由 `md/` 中的 Markdown 生成。这里是可复现的步骤。

## 依赖

- 一个能把 HTML 转成 PDF 的工具（本项目用的是 WordCraft CLI，商业工具；也可用 Chromium 的无头打印、Pandoc + LaTeX 等替代）
- 中文衬线/无衬线字体：思源宋体（Source Han Serif SC）、思源黑体（Source Han Sans SC）

## 步骤

1. 读取 `md/` 下每册目录中的章节文件，按文件名排序
2. 转成 HTML：元素选择器 + 内联样式（很多转换器不支持 class 选择器，内联最稳）
3. 逐章转 PDF（一章一个 PDF，天然分页；CSS `page-break` 在多数工具里不生效）
4. 拼接顺序：封面 → 册导言 → 插图页 → 目录 → 各章
5. 合并用 `pdfunite`（poppler-utils）或任意 PDF 合并工具

## 版式要点

| 项目 | 取值 |
| --- | --- |
| 纸张 | A4，页边距 20/17/18/17 mm |
| 正文 | 10.5 pt，行高 1.72，两端对齐 |
| 章标题 | 20 pt，`#14507a`，思源黑体 |
| 节标题 | 13.5 pt，`#14507a` |
| 代码块 | 8.6 pt 等宽，左侧 3 pt 竖线，浅灰底 |
| 表格 | 9 pt，表头 `#e8eef4` 底色 |
| 提示框 | 左侧 4 pt `#d99a2b` 竖线，`#fdf7ea` 底 |

## 插图

`figs/` 中的 SVG 是 A4 尺寸（595×842 pt）的整页图，转成 PDF 后直接插入到对应位置。
SVG 里的字体用系统字（Noto Sans CJK SC / 思源黑体），缺少字体时会回退到默认无衬线字体。
