## 40.1　Matrix

*难度：进阶 ｜ 篇幅：6.9 KB ｜ 所属：网络电话*

将要讲到：安装、配置、数据库、服务、用户管理、蜘蛛爬虫

[Matrix](https://matrix.org/) 是一个新的开放式联邦化的即时通信和 VoIP 生态系统。其包含服务端、[客户端](https://matrix.org/clients/)和[桥接工具](https://matrix.org/bridges/)，可以连接到已有的通信解决方案如[IRC](https://en.wikipedia.org/wiki/Internet_Relay_Chat)。

Arch Linux 的官方 Matrix 空间位于[#public-space:archlinux.org](https://matrix.to/#/#public-space:archlinux.org)。要想加入空间，请联系已加入空间的成员或 *@heftig:archlinux.org* 寻求邀请。想加入 Arch Linux CN 的官方 Matrix 房间可以参考 [Arch Linux 中文社区#Matrix 房间](../../00_关于与社区/Arch%20社区/Arch%20Linux%20中文社区.md#Matrix_房间)。一些国际社区有其自己的 Matrix 房间，请参阅[国际社区](../../06_软件与应用/列表/国际社区.md)以了解详细信息。

对于客户端，请参阅[应用程序列表/互联网#Matrix 客户端](../网络应用程序/应用程序列表_互联网.md#Matrix_客户端)。

您可以使用已有的 Matrix 服务器如 [https://matrix.org](https://matrix.org) 或创建您自己的服务器。下文是创建一台广泛使用的服务器的教程。

## 安装

Matrix 的服务端实现 **Synapse** 由 [matrix-synapse](https://archlinux.org/packages/?name=matrix-synapse)包 提供，其会创建一个 *synapse* 用户。

## 配置

安装完成后需要生成一个配置文件，*synapse* 用户应当能够读取该文件：

```
# generate_config --server-name my.domain.name \
                  --config-dir /etc/synapse \
                  --data-dir /var/lib/synapse \
                  --report-stats yes \
                  --generate-secrets \
                  --output-file /etc/synapse/homeserver.yaml
```

```
# generate_log_config -o /etc/synapse/my.domain.name.log.config \
                      -f /var/log/synapse/homeserver.log
```

```
# generate_signing_key --output_file /etc/synapse/my.domain.name.signing.key
```

```
# chown -R synapse:synapse /etc/synapse /var/log/synapse
```

请注意这会为指定的服务器名称生成相应的 SSL 和自签名证书，若您更改了服务器名称，则应重新生成。

> **注意：**若您的 Synapse 服务器可通过互联网访问，那么非常建议您为其设置[反向代理](https://github.com/element-hq/synapse/blob/develop/docs/reverse_proxy.md)。

## 数据库

Synapse 仅用 SQLite 测试服务器，操作时使用 Postgres。

要使用 Postgres，请安装 [python-psycopg2](https://archlinux.org/packages/?name=python-psycopg2)包。

> **注意：**您可在[官网的使用 Postgres 文档](https://github.com/element-hq/synapse/blob/develop/docs/postgres.md)中读到更多有关安装和配置的信息，注意如果您错过了这个步骤，您*需要*稍后执行迁移。在这个领域 SQlite 并不是很精通。

## 服务

[matrix-synapse](https://archlinux.org/packages/?name=matrix-synapse)包 包含 systemd 服务 `synapse.service`，其会按照配置文件 `/etc/synapse/homeserver.yaml` 以用户 *synapse* 启动 Synapse 服务端。

## 用户管理

您的新 synapse 服务器需要至少一个用户，可以执行以下命令创建您的默认非 root 用户：

```
[synapse]$ register_new_matrix_user -c /etc/synapse/homeserver.yaml http://127.0.0.1:8008
```

也可以使用一个 [matrix 客户端](https://matrix.org/ecosystem/clients/)，例如 [element-desktop](https://archlinux.org/packages/?name=element-desktop)包，或 [libpurple](https://aur.archlinux.org/packages/libpurple/)AUR 的 [purple-matrix-git](https://aur.archlinux.org/packages/purple-matrix-git/)AUR 插件。

## 蜘蛛爬虫

如需为链接预览等功能启用蜘蛛爬虫，请安装 [python-lxml](https://archlinux.org/packages/?name=python-lxml)包 和 [python-netaddr](https://archlinux.org/packages/?name=python-netaddr)包。之后在 `homeserver.yaml` 中设定 `url_preview_enabled: True`。欲使 synapse 服务器拒绝指向内部服务器的 GET 请求，请设定 `url_preview_ip_range_blacklist:`。

> **警告：**黑名单默认空白：不配置的话 synapse 服务器可以爬取您所有的内部主机。

可以取消一些黑名单示例的注释。把您本地的 IP 地址范围添加到列表中可以阻止 synapse 服务器尝试爬取它们。在编辑 `homeserver.yaml` 后，必须重启服务。

## 故障排除

### 只读文件系统

默认情况下，synapse 只能写入由服务文件设置的工作目录 (`/var/lib/synapse`)。当 synapse 写入另一个路径时，可能会发生写入错误，例如您设置了媒体存储于 `/var/lib/matrix-synapse/media`。

您可以创建一个 `synapse.service` 的[替换单元文件](../../01_安装与包管理/初始化/Systemd.md)并添加 `ReadWritePaths=*欲写入的路径*` 到 `[Service]` 节来允许 synapse 访问其他路径。

### 高内存占用

synapse 的内存占用可以通过安装 [jemalloc](https://archlinux.org/packages/?name=jemalloc)包 被大幅减少。要启用 *jemalloc* 内存管理器，[环境变量](../../02_系统管理与内核/系统管理/环境变量.md) `LD_PRELOAD` 需要按下方示例设置。可以修改 `/etc/default/synapse` 文件，systemd 会自动加载该配置中的环境变量。

```
/etc/default/synapse
```

```
LD_PRELOAD=/usr/lib/libjemalloc.so
```

启用 *jemalloc* 后，通过调整缓存设置可以进一步降低内存占用。

```
/etc/synapse/homeserver.yaml
```

```
caches:
  cache_autotuning:
    max_cache_memory_usage: 1024M
    target_cache_memory_usage: 758M
    min_cache_ttl: 5m
```

只有 *jemalloc* 启用时，`cache_autotuning` 中的设置才会工作。
