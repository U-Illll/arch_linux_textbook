# 第 22 章　无障碍

> 无障碍功能决定的是系统能不能装上去，而不是装好之后在桌面上调整的一项偏好。本章只有一节，按安装前、安装、配置系统、重新启动依次展开，是一条完整流程，需要无障碍支持的读者必须照这个顺序走完，某一环没做对，后面的步骤都无从补救；如果安装介质本来就能正常操作，用不上这些功能，可以跳过去读别的章节。最容易踩的坑是把无障碍当成装完再配的事：它要在安装前就启用，从启动安装介质那一步起就生效，等系统装好再想打开，前面的界面早已无法操作。

## 22.1　使用无障碍功能安装 Arch Linux

*难度：入门 ｜ 篇幅：3.1 KB ｜ 所属：无障碍*

将要讲到：安装前、安装、配置系统、重新启动

Arch Linux的官方安装媒介提供了多种辅助功能（ Accessibility ）：

- 朗读功能由[espeakup](https://archlinux.org/packages/?name=espeakup)包提供
- [盲文终端](https://en.wikipedia.org/wiki/Refreshable_braille_display)支持由[brltty](https://archlinux.org/packages/?name=brltty)包提供

本文档用于说明如何使用上述辅助功能安装[Arch Linux](../../00_关于与社区/关于%20Arch/Arch%20Linux.md)。

> **注意：**本页面仅说明与官方[Installation guide](../../01_安装与包管理/安装过程/安装指南.md)不同的步骤。

## 安装前

### 启动安装环境

> **注意：**安装媒介的引导加载程序在启动默认菜单项前有15秒的等待时间。

当安装媒介启动后，按`下`，然后按`回车`以使用朗读功能。

USB盲文显示设备会通过[udev](../../04_硬件与外设/硬件检测和故障排除/Udev.md)被自动检测到。

### 多个音频输出设备

如果电脑拥有多个音频输出设备，将会听到如下信息：*Please select your sound card for speech output*（请选择朗读功能使用的音频输出设备）。

在希望使用的音频输出设备听到“嘀”声时，按`回车`选择该音频输出设备。

## 安装

### 安装必要的软件包

在新安装的系统使用朗读功能，需安装[espeakup](https://archlinux.org/packages/?name=espeakup)包和[alsa-utils](https://archlinux.org/packages/?name=alsa-utils)包。如果使用盲文显示设备，需要安装[brltty](https://archlinux.org/packages/?name=brltty)包。

在使用[pacstrap(8)](https://man.archlinux.org/man/pacstrap.8)安装系统时，使用以下命令添加所需的软件包：

```
# pacstrap /mnt base linux linux-firmware espeakup alsa-utils
```

## 配置系统

### 音频输出设备

如果检测到 [#多个音频输出设备](#多个音频输出设备)，需要使用以下命令将安装媒介生成的`/etc/asound.conf`复制到新安装的系统：

```
# cp /etc/asound.conf /mnt/etc/
```

### 激活开机启动

为了在进入新安装的系统时使用朗读功能，需要将`espeakup.service`设置为开机自动启动（方法参照[systemd#使用单元](../../01_安装与包管理/初始化/Systemd.md#使用单元)）。

## 重新启动

在启动至新安装的系统后，朗读功能应该会自动开始工作。
