# 第五册　硬件与外设

> 笔记本、CPU、声卡、输入设备与硬件排障

## 这一册要解决什么

前四册把 Arch 装起来、跑起来、连上网，但那时你面对的还只是一台“计算机”，不是桌上这台具体的机器——它的声卡、键盘、触控板、风扇曲线和那几颗厂商专用按键。本册补的就是这段最后一公里：让通用的 Arch 落到真实硬件上之后，处处可用。

读完本册，你应该能用现成工具把硬件认全，说清总线上有哪些设备、各自挂了哪个内核模块，读得懂内核日志里与设备有关的那几行；遇到“没声音”“合盖不休眠”“触控板乱飞”“打印机装不上”时，先判断问题落在硬件、固件、驱动还是用户空间配置，再查对应页面；也知道该按部件查还是按机型查。

## 在九册中的位置

它承接第三册的内核与模块、系统恢复——本册几乎每页都在和内核模块、udev 规则、日志打交道；也依赖第二册的包管理，因为多数问题的解法说到底就是装对包、改对配置。

它同时是第六册《桌面与图形》的地基：输入设备与显示控制既是硬件的延伸，也决定桌面用得顺不顺手；声音同理，第七册的播放器与语音软件都建立在其中。本册还埋了颗种子——TPM 与固件更新，会在第九册讲加密与安全时被重新捡起。把硬件排在桌面之前是有意的：不少桌面故障追到最后，都落在设备驱动和输入栈上。

## 怎么读

建议从“硬件检测和故障排除”入手，先学会定位设备和读日志，这是全册通用手法；再读 CPU 那几节里的微码与调频，几乎每台机器都要做；之后按设备分叉：笔记本走笔记本相关章节，台式机直接进声音与输入设备。

联想机型页独占一章十五节，是全册最大的一块，但它是参考手册而非教材——只有机器对得上才值得逐节看，否则整章跳过。反倒是小新、红米这类中文市场机型页，补上了英文资料的空白，正好持有就别错过。专业音频与 JACK、Android 与 iOS 那几章可放到最后甚至略过，它们更像交叉玩法，不影响日常使用。

## 前置知识与常见误区

前置要求不高：会用包管理器安装和查询软件包，知道内核模块是什么、怎么临时加载，看得懂 /etc 下的配置文件，会用系统日志看报错。不需要会编程。

误区有四个。一是把硬件问题算在发行版头上：同型号不同批次、不同固件的支持差别可能很大，机型页上的经验也有保质期。二是层次没分清就改配置：键盘的按键要穿过扫描码、键码、键符号三层才变成字符，改错层等于白改；声音也一样，驱动、服务、音频服务器各有各的位置。三是忽视固件——笔记本的风扇、休眠、指纹常常要先解决固件与厂商 ACPI 的怪癖，而不是急着换调速工具。四是整段照抄别人的配置：机型页开头一般列了硬件信息，先确认处理器和显卡与作者一致，机器同名不等于同款。
