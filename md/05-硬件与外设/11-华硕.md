# 第 11 章　华硕

> 华硕的 Linux 支持散在型号页、适配文档和小工具之间，本章把它们收拢成一条线索：先弄清这台机器能跑到什么程度，再决定要不要碰显卡切换。建议先读《ASUS Linux》，另两节都挂在它的软件与参见上；再读《Supergfxctl》，要切显卡的机器绕不开，安装之前与预启动配置不能跳，这两节必读。《ASUS Eee PC F201E》只服务那台老上网本，用不上扫一眼即可。
> 
> 最易踩的坑是把 Supergfxctl 当成装上就灵的驱动，它只是切换与配置工具，前置条件没做对，配置再好也点不亮屏。

## 11.1　ASUS Eee PC F201E

*难度：入门 ｜ 篇幅：1.5 KB ｜ 所属：华硕*

将要讲到：硬件支持、参考

Asus Eee PC F201E 是一款轻巧的笔记本/超极本，与 [X201E](https://www.asus.com/Laptops/X201E/) 相似。显然，它仅在德国出售。

F201E 具有 11.6 英寸屏幕和 1.1 GHz Intel Celeron 847 处理器。它配备 4GB RAM，500GB 硬盘驱动器，集成 Intel HD 显卡，网络摄像头和 30 瓦 2 芯电池，最多可提供 5 小时的使用时间。

## 硬件支持

### 图形

可以使用 [xf86-video-intel](https://archlinux.org/packages/?name=xf86-video-intel)包。

### 音频

使用标准 [ALSA](../声音/ALSA.md) 和 [PulseAudio](../声音/PulseAudio.md) 设置。

#### 没有耳机声音

如果耳机插孔不起作用，请确保已安装并启动 [PulseAudio](../声音/PulseAudio.md)（通常从 X 会话启动，但在某些设置中可能需要手动启动）。

## 参考

## 11.2　ASUS Linux

*难度：入门 ｜ 篇幅：4.1 KB ｜ 所属：华硕*

将要讲到：软件、参见

ASUS Linux 是一套旨在提升在华硕笔记本上运行 Linux 的使用体验的工具，包括性能提升和功能驱动。它由 asusctl 和 [supergfxctl](Supergfxctl.md) 两部分组成，前者与内核模块 `asus-wmi` 通信以控制 BIOS 级别的功能，后者用于在双显卡机型上控制独立显卡。

该项目由 [Luke Jones](https://gitlab.com/flukejones) 维护，托管在 [GitLab](https://gitlab.com/asus-linux) 上。

## 软件

ASUS Linux 提供了许多软件包，详细请看下方子标题。

> **注意：**
>
> - 您可以在此定制仓库找到已编译的二进制软件包: [非官方用户仓库#g14](../../01_安装与包管理/非官方用户仓库/非官方用户仓库.md#g14), 由 [Luke Jones](https://gitlab.com/flukejones) 提供。
> - 官方建议使用此仓库安装 asus-linux 组件。此仓库由 asus-linux 开发者提供和维护。详见 [https://asus-linux.org/guides/arch-guide/](https://asus-linux.org/guides/arch-guide/)
> - 尽管该项目使用 G14 的名字，这**并不代表**其仅适用于华硕幻14设备。事实上，它几乎支持所有华硕 ROG 和 TUF 笔记本。

### asusctl

[asusctl](https://aur.archlinux.org/packages/asusctl/)AUR 是用于华硕 ROG 和 TUF 笔记本的命令行工具，拥有包括但不限于以下功能：

- 集成显卡 MUX 控制
- 键盘 RGB 控制 （不及 AURA/奥创中心）
- 风扇曲线调控
- 电池充电上限
- 屏幕快显
- AniMe Matrix 光显矩阵屏

使用方法详见 asusctl。

### supergfxctl

[supergfxctl](https://aur.archlinux.org/packages/supergfxctl/)AUR 是在华硕混合显卡笔记本上管理显卡切换功能的命令行工具，尤其是独立显卡 MUX 控制。

使用方法详见 [supergfxctl](Supergfxctl.md)。

### rog-control-center

[rog-control-center](https://aur.archlinux.org/packages/rog-control-center/)AUR 是 *asusctl* 和 *supergfxctl* 的图形化前端，不过功能有限。

### 定制内核


ASUS Linux 项目还维护了一套针对华硕移动端特化的内核补丁，并将其整合到一个定制内核当中。一般来说，您并不需要使用此内核，但在某些极端情况下（通常是最新的笔记本），您必须使用此内核才能使用您笔记本的一些特殊功能。

要使用定制内核，请安装 [linux-g14](https://aur.archlinux.org/packages/linux-g14/)AUR 和 [linux-g14-headers](https://aur.archlinux.org/packages/linux-g14-headers/)AUR。

> **注意：**
>
> - 如果您添加了 [G14 非官方仓库](../../01_安装与包管理/非官方用户仓库/非官方用户仓库.md#g14)，您可以直接使用 [pacman](../../01_安装与包管理/包管理器/Pacman.md) 安装上述 AUR 软件包。
> - 如果您正在尝试从原版内核切换为定制内核，您还必须将所有内核模块升级为 [DKMS](../../02_系统管理与内核/内核/DKMS.md) 版本。

## 11.3　Supergfxctl

*难度：进阶 ｜ 篇幅：5.9 KB ｜ 所属：华硕*

将要讲到：安装之前、安装、配置、用法、预启动配置、图形化工具

[supergfxctl](https://aur.archlinux.org/packages/supergfxctl/)AUR 是由 [ASUS Linux](ASUS%20Linux.md) 提供的，用于在混合图形笔记本上管理显卡切换功能的实用工具。

尽管 supergfxctl 最初是为华硕的 [Optimus](../../05_桌面与图形/图形/NVIDIA%20Optimus.md) 笔记本设计的，它也逐渐成为了能在任何使用[混合图形技术](../../05_桌面与图形/图形/混合图形技术.md)的笔记本上使用的独立工具。

## 安装之前

对于使用 Optimus 的笔记本，请确保已安装 [NVIDIA](../../05_桌面与图形/图形/NVIDIA.md) 私有显卡驱动。请勿安装 [xf86-video-intel](https://archlinux.org/packages/?name=xf86-video-intel)包。 如果安装了 [optimus-manager](https://aur.archlinux.org/packages/optimus-manager/)AUR 和 [bumblebee](https://archlinux.org/packages/?name=bumblebee)包 ，请卸载并确保在以下路径没有残余的 [NVIDIA](../../05_桌面与图形/图形/NVIDIA.md)， [Intel](../../05_桌面与图形/图形/Intel%20图形处理器.md) 或其他 PRIME 管理器的配置文件：

- `/etc/X11/xorg.conf.d/`
- `/etc/modprobe.d/`
- `/etc/udev/rules.d/`

### Initramfs 和内核参数

如果您的笔记本使用 NVIDIA 独立显卡， 您需要设置一些[内核参数](../../02_系统管理与内核/内核/内核参数.md)，方法见 [NVIDIA#DRM 内核级显示模式设置](../../05_桌面与图形/图形/NVIDIA.md#DRM_内核级显示模式设置)。 如果您的笔记本使用 AMD 独立显卡，您无需进行额外操作。

## 安装

您可以使用由 ASUS Linux 提供的[软件仓库](../../01_安装与包管理/非官方用户仓库/非官方用户仓库.md#g14)来安装。您也可以安装 [supergfxctl](https://aur.archlinux.org/packages/supergfxctl/)AUR 软件包，然后启用 `supergfxd.service`。

## 配置

配置文件保存在 `/etc/supergfxd.conf`。以下是一个样例配置文件：

```
supergfxd.conf
```

```
{
  "mode": "Hybrid",
  "vfio_enable": false,
  "vfio_save": false,
  "always_reboot": false,
  "no_logind": false,
  "logout_timeout_s": 180,
  "hotplug_type": "None"
}
```

## 用法

Supergfxctl 支持以下模式：`Integrated`，`Hybrid` 和 `VFIO`。它可以自行检测 MUX switch 是否处于 `AsusMuxDgpu` 模式。选项 `NvidiaNoModeSet` 会在重启系统时禁用 [NVIDIA](../../05_桌面与图形/图形/NVIDIA.md) GPU [内核模块](../../02_系统管理与内核/内核/内核模块.md)。

若要使用 MUX switch，您必须确保 asusctl 正在运行，详见 asusctl#Using the MUX switch。

### 显示支持的模式

以下命令可以显示您的笔记本支持的所有模式：

```
$ supergfxctl -s
```

### 获取当前模式

以下命令可以查询您显卡当前的模式：

```
$ supergfxctl -g
```

### 切换模式

以下命令可以将您显卡的模式切换为 `Hybrid`:

```
$ supergfxctl -m hybrid
```

## 预启动配置

### 使用 supergfxctl 配置显卡直通 (VFIO)

[VFIO](../../02_系统管理与内核/虚拟化/使用%20OVMF%20直通%20PCI.md) 显卡直通（GPU passthrough）可以通过编辑 `/etc/supergfxd.conf` 启用。在此配置文件中，[上游](https://gitlab.com/asus-linux/supergfxctl)建议将 `hotplug_type` 的值更改为 `Asus`，而不是 `None`。

```
/etc/supergfxd.conf
```

```
{
"vfio_enable": true,
"hotplug_type": "Asus"
}
```

详见 [ASUS Linux VFIO guide](https://asus-linux.org/guides/vfio-guide/)。

### 使用 supergfxctl 与 MUX switch

当系统处于 `Hybrid` 模式时，[nvidia-prime](https://archlinux.org/packages/?name=nvidia-prime)包 提供的 `prime-run` 命令可以让程序运行在独立显卡上。只要 MUX switch 已经启用，应用就不会出错，所以很适合需要高图形性能的场景。

### 在 Wayland 中使用 supergfxctl

自从 [Wayland](../../05_桌面与图形/Wayland/Wayland.md) 支持多显卡同步以来， 用户不再需要安装 supergfxctl，除非他们想使用 VFIO 或进一步限制耗电量。 可以使用 asusctl 切换到`AsusMuxDgpu` 模式，详见 asusctl#Using the MUX switch。
