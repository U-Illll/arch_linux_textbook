## 25.1　垃圾管理

*难度：进阶 ｜ 篇幅：5.9 KB ｜ 所属：软件列表*

将要讲到：创建垃圾桶、垃圾空间使用管理、问题解决

为防止误删文件，可以使用垃圾桶。为确保多个应用程序之间的兼容性，可以使用遵循 [FreeDesktop.org's Trash specification](https://specifications.freedesktop.org/trash-spec/latest) 的软件（CLI、GUI 或库）。

> **注意：**某些应用程序可以在每个文件系统中使用一个垃圾桶（请参阅规范）。

> **警告：**删除其他文件系统上的文件时，由于文件会在文件系统之间传输，因此使用垃圾桶可能会导致一些延迟。在这种情况下，你可能需要为每个文件系统创建一个垃圾文件夹（参见规范中的 `Trash directories`）。

## 创建垃圾桶


一些 GUI 文件管理器，如 [GNOME Files](../../05_桌面与图形/GNOME/GNOME_文件.md) 和 [Dolphin](../../02_系统管理与内核/文件管理/Dolphin.md) 本身就支持将文件移入垃圾桶。还有一些 CLI 工具：

- [glib2](https://archlinux.org/packages/?name=glib2)包 提供了一条 `gio trash *file...*`命令，用于将文件移入垃圾桶，而 `gio trash --empty` 则会清空垃圾桶。另请参见 [gio(1) § COMMANDS](https://man.archlinux.org/man/gio.1#COMMANDS) 中的 "trash"。要通过 `gio trash` 命令完全支持垃圾管理，需要安装 [gvfs](https://archlinux.org/packages/?name=gvfs)包 软件包。
- [kde-cli-tools](https://archlinux.org/packages/?name=kde-cli-tools)包 提供了一条 `kioclient5` 命令，可以使用 `kioclient5 move *file* trash:/` 将 `*file*` 移至垃圾桶。
- **trash-cli** — 实现 [FreeDesktop.org's Trash specification](https://specifications.freedesktop.org/trash-spec/latest) 的命令行界面。

: [https://github.com/andreafrancia/trash-cli](https://github.com/andreafrancia/trash-cli) || [trash-cli](https://archlinux.org/packages/?name=trash-cli)包

- **trashman** — 一个 Python 垃圾管理器。

: [https://github.com/Kwpolska/trashman](https://github.com/Kwpolska/trashman) || [trashman](https://aur.archlinux.org/packages/trashman/)AUR

- **rmtrash** — trash-put 与 GNUs rm 和 rmdir 兼容。

: [https://github.com/PhrozenByte/rmtrash](https://github.com/PhrozenByte/rmtrash) || [rmtrash](https://aur.archlinux.org/packages/rmtrash/)AUR

- **trash-d** — GNU rm 的直接替代品，注重兼容性，性能更好，用 D 语言编写。

: [https://github.com/rushsteve1/trash-d](https://github.com/rushsteve1/trash-d) || [trash-d](https://aur.archlinux.org/packages/trash-d/)AUR

- **trashy** — 用 rust 写成的 rm 和 trash-cli 简单、快速、功能丰富的替代品

: [https://github.com/oberblastmeister/trashy](https://github.com/oberblastmeister/trashy) || [trashy](https://aur.archlinux.org/packages/trashy/)AUR

- **gtrash** — 用 Go 编写的功能丰富的 CLI 垃圾管理器

: [https://github.com/umlx5h/gtrash](https://github.com/umlx5h/gtrash) || [gtrash-bin](https://aur.archlinux.org/packages/gtrash-bin/)AUR

- **rmw（ReMove to Waste）** — 一个可配置的 CLI 垃圾管理工具，可在 X 天后清除垃圾，并与 [FreeDesktop.org's Trash specification](https://specifications.freedesktop.org/trash-spec/latest) 集成，用 C 语言编写

: [https://theimpossibleastronaut.com/rmw-website/](https://theimpossibleastronaut.com/rmw-website/) || [rmw](https://aur.archlinux.org/packages/rmw/)AUR

## 垃圾空间使用管理

为了防止垃圾桶占用过多空间，您可以自己清空垃圾桶，或者制定清理政策

### 软件列表

- **autotrash** — 自动清除旧垃圾文件的工具

: [https://github.com/bneijt/autotrash](https://github.com/bneijt/autotrash) || [autotrash](https://aur.archlinux.org/packages/autotrash/)AUR

### 标准


- 确保至少有 x MB 的可用空间
- 删除超过 x 天的文件
- 只有当可用空间小于 x MB 时才会清空（结合前面的标准很有用）
- 垃圾桶最大大小
- 文件大小
- 文件类型
- 原始路径

### 自动化

要自动清空垃圾桶，可以使用 [cron](../../02_系统管理与内核/系统管理/Cron.md)、[systemd/Timers](../../02_系统管理与内核/系统管理/Systemd_定时器.md) 或 inotify（使用 inotify，只有新的删除才会触发垃圾桶自动清空）。

## 问题解决

### 无法找到或创建垃圾目录

#### 外置硬盘

`/etc/fstab` 可能未正确设置。请注意，`ID` 必须用自己的用户 ID 替换通过 `$ id`。

```
/etc/fstab
```

```
# <device>                                <dir>              <type>    <options>         <dump> <fsck>
UUID=75667752-8b06-11ea-bc55-0242ac130003 /externalDrive     ntfs-3g   defaults,uid=ID   0      1
```

确保驱动器根目录包含 `~/.Trash-1000/{expunged,files,info` 并为该目录和子目录设置相关读取权限。

## 25.2　剪贴板

*难度：进阶 ｜ 篇幅：13.5 KB ｜ 所属：软件列表*

将要讲到：历史、选区、禁用中键粘贴、工具、管理器、参见

根据[维基百科](https://zh.wikipedia.org/wiki/%E5%89%AA%E8%B4%B4%E6%9D%BF)：

: 剪贴板（英语：clipboard），有时也称剪切板、剪贴簿、剪贴本。它是一种软件功能，通常由操作系统提供，作用是使用复制和粘贴操作短期存储数据和在文档或应用程序间转移数据。

## 历史

在X10（[1985](https://en.wikipedia.org/wiki/X_Window_System#Release_history)），引入了[剪切缓冲区](https://en.wikipedia.org/wiki/X_Window_selection#Cut_buffers)。这些是有限的缓冲区，用于存储任意文本，并被大多数应用程序使用。然而，它们效率低下，且实现方式各异，因此引入了选择功能。剪切缓冲区现在已经被长期弃用，尽管一些应用程序（如xterm（英语：[xterm](https://wiki.archlinux.org/title/xterm)））可能仍然有对它们的遗留支持，但不建议使用它们。

## 选区

Freedesktop.org 将两种主要[选区](https://en.wikipedia.org/wiki/X_Window_selection#Selections)描述如下：

**PRIMARY**
: 用于当前选定的文本，即使该文本没有显式复制，并用于中键粘贴。在某些情况下，使用快捷键也可以粘贴。
**CLIPBOARD**
: 用于涉及键盘快捷键或菜单项的显式复制/粘贴命令。因此，它的行为类似于 Windows 上的单剪贴板系统。与 PRIMARY 不同，它还可以处理[多种数据格式](https://stackoverflow.com/questions/3571179/how-does-x11-clipboard-handle-multiple-data-formats)。

大多数 [Xorg](../../05_桌面与图形/X%20服务器/Xorg.md) 程序，包括 [Qt](../../07_开发与工具/控件工具集/Qt.md) 和 [GTK](../../07_开发与工具/控件工具集/GTK.md) 应用程序，遵循此行为。尽管 [ICCCM](https://tronche.com/gui/x/icccm/) 还定义了 SECONDARY 选区，但它没有一个广泛认同的用途。尽管名称上有三种选区，但它们基本上都是“剪贴板”。与旧的“剪切缓冲区”系统不同，只有一个应用程序可以控制或“拥有”一个选区。这避免了选区操作中的不一致性。

请参见[快捷键](../../04_硬件与外设/键盘/快捷键.md)页面，列出了许多程序的默认快捷键。

还需要注意的是，根据选择协议，直到粘贴之前，什么都不会被复制。例如，如果你在终端窗口中选择了一些文字，关闭终端后想要粘贴到其他地方，它将无法工作，因为终端已经消失，文本并没有被复制到任何地方。如果你希望关闭终端窗口后保存文字，考虑安装[剪贴板管理器](剪贴板.md)。

> **注意：**[剪贴板管理器](剪贴板.md)可以显著改变用户体验，例如，它们可能会同步 PRIMARY 和 CLIPBOARD 选择，以模拟单一剪贴板系统。

## 禁用中键粘贴

以下方法通过自动清除 PRIMARY 来禁用中键粘贴行为，而不禁用中键按钮或更改其其他功能（如在新标签页中打开或滚动）。

### 全局禁用

#### 使用 sxhkd

使用 [sxhkd](../../04_硬件与外设/键盘配置/Sxhkd.md)，在[配置文件](../../04_硬件与外设/键盘配置/Sxhkd.md#配置)中添加以下内容：

```
~button2
    ;echo -n | xclip -in
```

该命令使用[xclip](https://archlinux.org/packages/?name=xclip)包。请参见 [sxhkd#用法](../../04_硬件与外设/键盘配置/Sxhkd.md#用法)配置 sxhkd 以实现自动启动。

#### 使用 xsel

运行脚本：

```
#!/bin/sh
while true; do
    xsel --follow --input --nodetach </dev/null
done
```

### 特定应用程序禁用

- [GTK](../../07_开发与工具/控件工具集/GTK.md)——参见 [GTK#禁用鼠标中键粘贴](../../07_开发与工具/控件工具集/GTK.md#禁用鼠标中键粘贴)
- [Firefox](../Mozilla/Firefox.md)——参见[Firefox#中键单击行为](../Mozilla/Firefox.md#中键单击行为)
- [LibreOffice](../办公/LibreOffice.md)——可以在**工具 > 选项 > LibreOffice > 查看 > 鼠标**中禁用
