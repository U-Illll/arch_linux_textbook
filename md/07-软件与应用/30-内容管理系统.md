# 第 30 章　内容管理系统

> 本章只解决一件事：在 Arch 上把 Drupal 装起来并真正可用。安装不难，难的是配套——GD 库、Postfix、Cron、上传进度条缺哪一样，缩略图、发信、后台任务、大附件上传就卡哪一样。
> 
> 本章仅一节，安装是必读主干，从头做到尾，别跳读；GD 库与上传进度条关系到图片处理和大附件上传，务必做完；Postfix 服务于站内发信，兼容 Xampp 只对已有环境的人有意义，都可跳过。最容易踩的坑是把 Cron 当成可选步骤——后台行为不靠人点，缺了它，搜索索引与缓存清理一直不动。

# 安装

## 安装Drupal

### 从源安装

1.  安装 [drupal](https://archlinux.org/packages/?name=drupal)包。
2.  使用自己喜欢的编辑器，编辑文件`/etc/php/php.ini`

    ```
    # vim /etc/php/php.ini
    ```

    找到下面一行："`;extension=json.so`"，如果有注释就去掉注释（第一个字符“;”），如果没有这行就在这个文件的`[PHP]`区块添加。
    对于Drupal 7来说，还需要启用数据库的PDO扩展，例如MySQL， `extension=pdo_mysql.so`。
3.  打开文件`/etc/httpd/conf/httpd.conf`

    ```
    # vim /etc/httpd/conf/httpd.conf
    ```

    找到以"`<Directory "/srv/http">`"（根据自己的Drupal安装目录而定）开始的部分，找到"`AllowOverride None`"，替换为"`AllowOverride All`"，这样可以启用Drupal的简洁连接（clear URL's）。
4.  重启Apache

    ```
    /etc/rc.d/httpd restart
    ```
