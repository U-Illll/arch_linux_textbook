## 怎么读

**系统学习**：从第零册顺序读到第九册，约两到三个月。

**装完就查**：第零册前三章 + 第二册的《安装过程》《启动过程》《包管理》三章，其余按需检索。

**专题深入**：有 Linux 基础的话，直接进第四册（网络）、第六册（桌面）、第九册（安全）；每册开头的册导言会说明前置知识。

## 每章的结构

- **章导语**：这一章解决什么问题、哪些小节必读、常见误区
- **本节导读**：难度、篇幅、将要讲到的内容
- **正文**：维基原文，命令、配置、表格原样保留
